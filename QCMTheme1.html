Variables locales ou globales

On reprend l'exemple : float pi = 3.141592654; (déclarée en début de fichier), float perimetre; (déclarée en début de fichier), float per; (déclarée dans la fonction), float ray (paramètre de la fonction).

1) La variable "pi" est une variable globale

2) La variable "perimetre" est une variable globale

3) La variable "per" (définie dans la fonction) est une variable globale

4) La variable "ray" (paramètre) est une variable globale

5) Une variable globale est accessible de n'importe quel endroit du programme
