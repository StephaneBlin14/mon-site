Configurer un switch Cisco avec PuTTY

Fiche de référence CLI : accéder au switch, sécuriser l'accès, configurer les interfaces et les VLAN, puis vérifier et sauvegarder.

Avant de commencer

1. ConnecterRelier le PC au port console, ou se connecter par SSH si le réseau est déjà configuré.
2. Ouvrir PuTTYConsole série : choisir le bon port COM et généralement 9600 bauds, 8 bits, sans parité, 1 bit d'arrêt, contrôle de flux désactivé.
3. Passer en configurationEntrer les commandes dans l'ordre et vérifier chaque étape.

Les exemples ci-dessous correspondent à la syntaxe courante des switches Cisco IOS. Certaines commandes varient selon le modèle, la version IOS et les droits disponibles.

1. Se connecter au switch

Appuyer sur Entrée dans la fenêtre PuTTY. Selon l'état initial, l'invite peut ressembler à Switch> ou demander un identifiant.

InviteSignificationCommande suivante
Switch>Mode utilisateur : commandes limitées.enable
Switch#Mode privilégié : commandes de consultation et administration.configure terminal
Switch(config)#Mode configuration globale.Configurer le switch.
Switch(config-if)#Configuration d'une interface.Configurer le port sélectionné.
enable configure terminal

2. Commandes de base

Nommer le switch et désactiver la recherche DNS

hostname SW-ATELIER no ip domain-lookup

hostname change le nom affiché dans l'invite. no ip domain-lookup évite qu'une faute de frappe soit interprétée comme un nom à résoudre.

Se déplacer dans les modes

end configure terminal exit ? do show running-config

end revient au mode privilégié. exit remonte d'un niveau. ? affiche l'aide disponible. Depuis un sous-mode de configuration, do permet de lancer une commande EXEC, par exemple do show running-config.

3. Sécuriser les accès

À savoir : les mots de passe ci-dessous sont des exemples pédagogiques. Remplacez-les par des valeurs robustes et conformes à la politique de l'établissement. Ne copiez pas ces exemples sur un réseau de production.

Mot de passe du mode privilégié

enable secret MonMotDePasseFort

Mot de passe de la console

line console 0 password ConsoleExemple login exit

Accès distant SSH (exemple à adapter)

ip domain-name atelier.local username admin privilege 15 secret MotDePasseFort crypto key generate rsa ip ssh version 2 line vty 0 15 login local transport input ssh exit

La génération RSA peut demander une taille de clé ; choisir une taille adaptée à l'IOS, par exemple 2048 bits si elle est proposée. Certains modèles utilisent line vty 0 4. Configurez d'abord une adresse IP joignable et vérifiez les recommandations de sécurité de votre organisation.

Chiffrer les mots de passe de lignes dans la configuration

service password-encryption

Cette commande masque les mots de passe de lignes dans l'affichage de la configuration, mais ce mécanisme n'est pas une protection cryptographique forte. Privilégier enable secret et les secrets de comptes.

4. Configurer l'adresse IP de gestion

Sur un switch de couche 2, l'adresse de gestion est souvent placée sur une interface VLAN (SVI), et non directement sur un port physique.

interface vlan 1 ip address 192.168.1.10 255.255.255.0 no shutdown exit ip default-gateway 192.168.1.1

Exemple : le switch a l'adresse 192.168.1.10/24 et la passerelle du réseau est 192.168.1.1. L'interface VLAN doit être active et associée à au moins un port actif dans ce VLAN pour que l'SVI soit opérationnelle sur de nombreux switches.

Adaptez l'adresse IP, le masque, le VLAN de gestion et la passerelle à votre plan d'adressage. Vérifiez qu'aucun autre équipement n'utilise déjà cette adresse.

5. Créer un VLAN et affecter un port

Créer le VLAN 10

vlan 10 name INFORMATIQUE exit

Placer un port en mode access dans le VLAN 10

interface gigabitEthernet 0/1 switchport mode access switchport access vlan 10 no shutdown exit

Adaptez le nom de l'interface à votre modèle : par exemple fastEthernet 0/1, gigabitEthernet 1/0/1, etc.

Configurer un lien trunk (si nécessaire)

interface gigabitEthernet 0/24 switchport mode trunk switchport trunk allowed vlan 10,20 no shutdown exit

Un trunk transporte plusieurs VLAN entre équipements compatibles. La syntaxe et la négociation du trunk peuvent varier selon le modèle ; ne configurez pas un trunk sur un port utilisateur ordinaire.

Éteindre ou réactiver un port

interface gigabitEthernet 0/2 shutdown no shutdown exit

shutdown désactive administrativement le port ; no shutdown le réactive.

6. Vérifier la configuration

CommandeUtilité
show running-configAfficher la configuration actuellement en mémoire vive.
show startup-configAfficher la configuration sauvegardée au démarrage.
show ip interface briefVoir les interfaces, leurs adresses IP et leur état.
show interfaces statusVoir l'état des ports, le VLAN et la vitesse (si pris en charge).
show vlan briefAfficher les VLAN et les ports associés.
show interfaces trunkVérifier les liens trunk.
show mac address-tableConsulter les adresses MAC apprises par le switch.
show versionAfficher le modèle, la version IOS et des informations de démarrage.
ping 192.168.1.1Tester la connectivité IP vers une adresse cible.

Astuce : dans la configuration, show running-config peut être précédé de do lorsque vous êtes encore dans un sous-mode de configuration.

7. Sauvegarder la configuration

end copy running-config startup-config

Valider le nom de destination proposé avec Entrée. La configuration en cours est alors copiée dans la configuration de démarrage, conservée après redémarrage.

Attention : si vous oubliez cette étape, vos changements peuvent être perdus au redémarrage. Avant toute modification importante, sauvegardez la configuration existante et assurez-vous de disposer d'un accès de secours.

8. Générateur de commandes

Renseignez les champs pour produire un exemple de configuration adapté. Les commandes générées ne sont pas envoyées automatiquement au switch.

hostname SW-ATELIER interface vlan 1 ip address 192.168.1.10 255.255.255.0 no shutdown exit ip default-gateway 192.168.1.1
